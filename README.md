# 🧠 Psychological Clinic Website

![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)
![Type](https://img.shields.io/badge/Project-Institutional_Website-blue?style=for-the-badge)

A modern, clean, and responsive institutional website developed for a **psychological clinic**, focused on trust, accessibility, and user experience.  
This project showcases my ability to design and build real-world web solutions aligned with business and human-centered needs.

---

## 🌿 About the Project

This website was designed to represent a **professional psychology clinic**, prioritizing emotional comfort, clarity, and credibility.  
Every visual and structural decision was made to create a welcoming digital environment — essential for mental health services.

The project reflects real client needs, such as:
- Clear professional presentation  
- Easy access to contact information  
- Calm and accessible visual identity  
- Responsive layout for all devices  

---

## ✨ Features

✔ Fixed and intuitive header navigation  
✔ Clean and calming color palette  
✔ Responsive design (mobile, tablet, desktop)  
✔ Semantic and accessible HTML  
✔ Organized and maintainable structure
